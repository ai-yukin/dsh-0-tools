# 回归测试

两套独立验证，覆盖 v1.11.0 的两处关键改动。

## `port-probe.test.mjs` — 测速代理端口探测

对应 bug：host 端从 3095 起自增最多 20 个端口（3095–3114），浏览器端却只探 3095–3099。
当 3095–3099 被**非本插件的本地服务**占住时，本实例的真实代理落到 3100+，
浏览器探不到 → `no_proxy` → 测速静默失效。旧判定`r.ok || r.status === 204`
还会把任何回 200 的无关服务误认成代理。

跑法（需Node 22+）：
```bash
node test/port-probe.test.mjs
```
7 个场景：正常命中 / 旧上限内 / 旧代码失手边界 / 中段 /范围上界 /
旧代码误连对照 / 全是占位者时应返回 null。

## `verify-gate.py` — 安装脚本版本闸门

对应逻辑：安装脚本只拦 DSH 0.3+（0.1.5 ~ 0.2.x 一律放行）。
校验 `install.bat` 的 findstr 与 `install.sh` 的 grep 判定等价且正确。

跑法：
```bash
python test/verify-gate.py
```
20 个版本号：0.1.x / 0.2.x 全放行，0.3.x / 0.9.x / 1.x / 2.x 全拦截。

⚠️两者都**不要**用带代理的环境跑端口测试（代理会劫持 127.0.0.1 请求）。
