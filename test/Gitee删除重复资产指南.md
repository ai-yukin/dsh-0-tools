# Gitee 手动删除重复资产操作指南

## 要删的是什么

Gitee Release `v1.14.0` 里有个多余文件 **`v1140.zip`**，和 `dsh-0-tools-v1.14.0.zip` 内容完全相同（都是 8,330,146 bytes）。

**原因**：我第一次上传时本地文件名是 `v1140.zip`，Gitee 保留了原名。后来重新上传了正确命名的文件，但第一个删不掉（见末尾「为什么 API 删不掉」）。

**影响**：不影响使用。用户下载 `dsh-0-tools-v1.14.0.zip` 正常。只是列表里多个重复项，看着乱。

---

## 操作步骤（网页端，约 30 秒）

你截图里已经看到入口了 —— **右侧栏「发行版 (1)」下面那个 `v1.14.0`**，点它。

1. 进Release 页
   在仓库主页右侧栏找到 **发行版** 区块，点下面的 **`v1.14.0`**。
   （或直接打开：`https://gitee.com/ai-yukin/dsh-0-tools/releases`）

2. 展开附件列表
   页面往下滚到**「附件」**区域，会看到 4 个文件：

   | 文件名 | 大小 | 处理 |
   |---|---|---|
   | `v1140.zip` | 8.3 MB | **← 删这个** |
   | `dsh-0-tools-v1.14.0.zip` | 8.3 MB | 保留 |
   | `v1.14.0.zip` | 源码包 | 保留（Gitee 自动生成） |
   | `v1.14.0.tar.gz` | 源码包 | 保留（Gitee 自动生成） |

3. 删除
   把鼠标移到 **`v1140.zip`** 那一行，**行右侧会出现「删除」按钮**，点它 → 确认。

4. 验证
   刷新页面，`v1140.zip` 不见了，只剩 3 个文件 → 完成。

---

## 如果没看到「删除」按钮

Gitee 的附件删除入口比较隐蔽，按顺序试：

- 先把鼠标**停在那一行**（不是点在文件名上），按钮才会浮现
- 有些版本需要在附件区右上角先展开「管理」
- 如果你的账号不是仓库管理员，压根不会有删除权限 → 换个账号或找我处理

## 为什么 API 删不掉（顺带记录）

不是我没试，是 Gitee 的 API 少返回了关键字段：

`GET /api/v5/repos/:owner/:repo/releases` 返回的每个 asset **只有两个字段**：

```json
{
  "name": "v1140.zip",
  "browser_download_url": "https://..."
}
```

**没有 `id`**。而删除接口 `DELETE .../releases/:id/attach_files/:asset_id` 必须传 asset id。

我上传时拿到的 id 是 `3360329`，但用这个 id 去删返回 **404**（试了 3 次都一样）——
说明 Release 详情接口的 id 和删除接口期望的 id 对不上，
而列表接口又不给 id，**形成了死结，只能网页端删**。

> 对比 GitHub：GitHub 的 `GET releases` 每个 asset 都带 `id`，可以完全用 API 删。
