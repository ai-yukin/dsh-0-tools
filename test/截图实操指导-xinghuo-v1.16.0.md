## 四、截图纪律

### 必须打码

**API Key 是唯一必须打码的东西**，只出现在**新用户页第 6 张**。

- 从 `ak-` 开始到结束**整串盖住**
- 不要只盖中间几个字符 —— 官方示例是 `ak-f30b1********fc84b82e86a` 这种两头露出来的形式
- 用**实心**黑/灰色块或马赛克，**不要半透明**（压缩后可能透出来）

> 老用户页 4 张**都不含真实 Key**（第 4 张列表是 `***********` 脱敏），无需打码。

### 画面要求

- 浏览器窗口宽度约 **1400–1600px**，与旧教程页比例一致
- 关键按钮/字段用红框或箭头标出（推荐）
- 不含书签栏、其他标签页标题、桌面壁纸

### 内容准确性

若页面上显示的**接口地址 / Model ID / API Key 三项**与教程页核对表不符，
说明开通的不是 Spark-X2.5-1.7B，**先别截图**，回模型广场重新确认。

⚠️ 特别提醒：模型广场里还有一个**同名的 Spark-X2.5（293B）**，那个**要收费**
（输入 0.96 元/百万 tokens）。要拍的是 **1.7B** 版本，卡片上标着「1M」和「0 元」。
**授权管理弹窗里也有这个坑**（`Spark-X2.5` / `Spark-X2.5-4B` / `Spark-X2.5-1.7B` 三行紧挨着），
所以第 3 张务必拍到能看清 `-1.7B` 后缀。

## 六、两页流程口述版（拍摄时对照）

**新用户（6 步）**
1. 微信扫码登录讯飞开放平台（**无需实名**）
2. 进星辰 MaaS 模型广场 → 找 Spark-X2.5-1.7B（标「1M」「0 元」）→ 点「API 调用」
3. 弹窗第一步「选择 API Key」→ 点「+ 创建 API Key」→ 填名称（建议 `dsh-0-tools`，上限 30 字符）→ 创建
4. 看到「该 API Key 暂未开通模型服务」→ 勾选协议 → 点「开通服务」
5. 第二步调用示例 → 复制 `ak-` 开头的 Key
6. 核对三项（接口地址 / Model ID / API Key）

**老用户（4 步）—— ⭐ 与新用户完全不同**
1. 微信扫码登录（用原来那个账号）
2. **左侧边栏「模型服务」→「API Key 管理」** → 找到你原来那个 Key → 点右侧**「授权管理」**
3. 弹窗里勾选 **`✓ Spark-X2.5-1.7B`**（**别勾 293B 的 Spark-X2.5，那个收费**）→ 点「确认授权」
4. 回列表点那一行的**「复制」**按钮 → 拿到 `ak-` 开头的 Key → 核对三项

⭐ **老用户的核心认知（v1.16.0 修正）**：

- 旧版本这里写的是「Key 存在 ≠ 已开通模型，要点『开通服务』」—— **这是错的**。
- 正确说法是：**老 Key 的服务早就开通过了，它只是没有新模型的调用权限。**
  所以动作是**「授权管理」勾模型**，不是「开通服务」。
- 「开通服务」只属于**刚创建的新 Key**（新用户流程第 4 步）。
- 判据：如果你看到「该 API Key 暂未开通模型服务」→ 这是**新 Key**，去新用户页；
  如果你只看到 Key 列表和「授权管理」→ 这是**老 Key**，走本页。
