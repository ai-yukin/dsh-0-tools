讯飞星火 · 更新 API Key

你已经创建过讯飞的 API Key 了 —— 只需给那个 Key 授权新模型并复制，约 2 分钟

已经创建过讯飞的 API Key？走这一页就够了，全程约 2 分钟。
你不需要注册账号、不需要创建新 Key、不需要点「开通服务」 —— 只要给原来那个 Key授权一下新模型，再复制出来就行。
（还没有 API Key / 从没用过讯飞？请看 新用户申请教程）
为什么要更新？
你原来用的免费模型 Spark Lite 已被讯飞官方下架，即使实名认证也领不到「无限量」礼包， 所以你现在的 Key 调不动任何东西。这不是 Key 坏了，是模型没了。

更关键的一点：在零号工具里，你的讯飞配置不会自动修好。 新旧是两套互不相通的密钥体系，插件只能改端点、改不了 Key —— 所以它做不到自动迁移。 结果是：自动路由会把这个不可用的讯飞绕开、切到别的模型， 界面上看起来一切正常，但你实际上一直没在用讯飞。
1登录讯飞星辰 MaaS 平台
访问 https://maas.xfyun.cn/， 用你原来那个讯飞账号登录（微信扫码即可）。

登录后先确认一件事：你要用的是哪个 Key？ 如果你当年在 Spark Lite 时代建过 Key，它可能也在这个平台里（模型广场换平台了，账号是同一个）， 那就继续用它 —— 不用新建。

待补截图：讯飞开放平台登录页，需拍到微信扫码登录入口。
2左侧「模型服务」→「API Key 管理」
登录后在左侧边栏找到「模型服务」，点开后选 「API Key 管理」。

这个页面会列出你账号下所有的 API Key，每行显示：
  • 名称（你自己起的那个名字，比如「零号工具-DSH免费模型」）
  • API Key（*********** 形式，平台已脱敏）
  • 创建时间
  • 操作：「授权管理」、「重命名」

找到你之前用的那一行，点它右侧的「授权管理」。

⚠️ 不要点「创建 API Key」 —— 你已经有 Key 了，重建一个反而要重新走开通流程。
images/xinghuo-upgrade/02-APIKey管理列表.png
待补截图：左侧边栏「模型服务」展开后的「API Key 管理」入口，以及 Key 列表页（名称 /脱敏 Key / 创建时间 / 「授权管理」按钮）。这是本页最关键的一张图
3在「授权管理」里勾选 Spark-X2.5-1.7B，点「确认授权」
点「授权管理」后会弹出一个模型勾选窗口，标题是你那个 Key 的名字， 里面是一列模型复选框（共 40 个）。

只需要勾一个：✓ Spark-X2.5-1.7B
特别小心，别勾错这两个：
  • Spark-X2.5（293B）—— 要收费，输入 0.96 元 / 输出 3.6 元每百万 tokens
  • Spark-X2.5-4B —— 不是我们要的那个
认准名字里的 「-1.7B」。勾好后点「确认授权」。

为什么老用户是「授权」而不是「开通服务」？ 因为你的 Key 早就开通过服务了，它只是没有这个新模型的调用权限。 「开通服务」是给刚创建的新 Key用的第一步，老 Key 不需要重走那一步。
images/xinghuo-upgrade/03-授权管理勾选.png
待补截图：「授权管理」弹窗，需拍到模型复选框列表，并且要能看清 Spark-X2.5-1.7B 那一行已被勾上，同时能看清上面的 Spark-X2.5（293B）以便对比警示。
4回到列表，点「复制」拿到 API Key
确认授权后自动回到刚才的 API Key 管理列表页。 在你那一行最右侧点「复制」按钮，即可复制完整 Key。

注意：列表里显示的是 ***********（平台脱敏）， 不能直接复制 —— 必须点那一行的复制按钮才能拿到完整的 ak- 开头的字符串。

顺便核对这三项：
项目应显示为
接口地址https://maas-api.cn-huabei-1.xf-yun.com/v2
Model IDspark-x2.5-1.7b
API Key以 ak- 开头的长字符串
接口地址和 Model ID 零号工具已内置，你不需要手动填， 只需要把 Key 粘进去。有一项对不上就会调用失败，而报错往往看不出是哪一项错了。
images/xinghuo-upgrade/04-复制APIKey.png
待补截图：API Key 列表里的「复制」按钮那一列。平台显示的是 ********** 脱敏值，这张图天然不含真实 Key，可以直接拍。
重要：新密钥是「一段」，不是旧教程里的「两段」。
旧版 Spark Lite 的 APIKey:APISecret 冒号拼接格式已废弃。
现在只要 ak- 开头的单个字符串，直接粘贴，不要拼接、不要加引号。
⚠️ 最后一步别忘了：回到零号工具的配置中心， 找到讯飞星火卡片，粘贴新 Key 覆盖掉旧的。
只在官网授权而不回零号工具粘贴新 Key 的话，插件里存的还是那个调不动的旧配置。
常见问题：
  1. 左侧边栏找不到「API Key 管理」 —— 在「模型服务」下面，不是「模型广场」里面。平台改版后入口换了位置。
  2. 授权时勾了 Spark-X2.5（没勾 -1.7B） —— 那个要收费。取消勾选，改勾 Spark-X2.5-1.7B。
  3. 报 401 / 「apikey not found」 —— 多半是把 Model ID 或接口地址当 Key 填了，或复制时带了引号/空格。只填 ak- 开头那一段。
  4. 报「model not found」 —— 授权的不是 Spark-X2.5-1.7B，回第 3 步重新勾一次。
  5. 提示额度不足 —— 「限时免费」有到期时间，到期后需重新确认授权或改用其他免费模型。
  6. 提示「该API Key 暂未开通模型服务」 —— 说明你这个 Key 是刚建的、还没开通过服务。那就改看新用户申请教程，走「开通服务」那一步。

最后一步：填入零号工具

把刚才复制的 ak- 开头的 API Key 粘贴到下方，点击按钮跳转到 DSH 完成填充。
