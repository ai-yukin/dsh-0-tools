讯飞星火 · 更新 API Key

你已经创建过讯飞的 API Key 了 —— 只需重新开通并复制，约 2 分钟

已经创建过 API Key？走这一页就够了，全程约 2 分钟。
你不需要注册账号、不需要创建新应用、不需要重新填任何信息 —— 只需要回到那个 API Key，点一下「开通服务」，然后把新格式的 Key 复制出来。
（还没有 API Key / 从没用过讯飞？请看 新用户申请教程）
为什么要更新？
你原来用的免费模型 Spark Lite 已被讯飞官方下架，即使实名认证也领不到「无限量」礼包， 所以你现在的 Key 调不动任何东西。这不是 Key 坏了，是模型没了。

更关键的一点：在零号工具里，你的讯飞配置不会自动修好。 新旧是两套互不相通的密钥体系，插件只能改端点、改不了 Key —— 所以它做不到自动迁移。 结果是：自动路由会把这个不可用的讯飞绕开、切到别的模型， 界面上看起来一切正常，但你实际上一直没在用讯飞。
1打开模型广场，找到 Spark-X2.5-1.7B
访问 https://maas.xfyun.cn/modelSquare 并用你原来的讯飞账号登录（微信扫码即可）。

在模型列表里找到 Spark-X2.5-1.7B（卡片上标注「1M」上下文、 0 元/百万 tokens），点击进入详情页，然后点「API 调用」。
images/xinghuo-upgrade/01-模型详情页API调用按钮.png
待补截图：Spark-X2.5-1.7B 模型详情页，需拍到「API 调用」按钮，以及卡片上的「0 元/百万 tokens」标注。
2在弹窗里选中你原来的那个 Key
点「API 调用」后会弹出「第一步：选择 API Key」窗口，里面会列出你已有的 Key。 找到你之前用的那一个（名字可能是你自己起的，比如「零号工具-DSH」），点击选中它。

选中后你会看到这句话：
「该 API Key 暂未开通模型服务，点击下方「开通服务」按钮即可开通并正常调用。」
这句话是正常的，不是出错。它只是说：你这个 Key 还没开通 Spark-X2.5-1.7B 这个模型， 下一步点「开通服务」就行。

如果列表里一个 Key 都没有，才需要点「+创建 API Key」新建一个 —— 但那说明你其实还没配置过， 请改看新用户申请教程。
images/xinghuo-upgrade/02-选择APIKey弹窗.png
待补截图：「第一步：选择 API Key」弹窗，需拍到已有 Key 列表（名字 + 脱敏后的 Key）、以及那句「该 API Key 暂未开通模型服务」提示。这是本页最关键的一张图。
3勾选协议，点「开通服务」
在同一个弹窗里，勾选「我已阅读并同意计费说明、服务协议及《用户使用须知》」， 然后点击 「开通服务」按钮。

Spark-X2.5-1.7B 的定价是 0 元/百万 tokens，开通本身不产生费用。
images/xinghuo-upgrade/03-开通服务.png
待补截图：勾选协议复选框 + 「开通服务」按钮。
4复制 API Key
开通成功后，弹窗会进入「第二步：调用示例」，同时自动生成完整的调用示例。 页面下方会显示这个 Key 的信息：
  1. API Key：以 ak- 开头的长字符串 —— 这就是要填进零号工具的东西
  2. Model ID：形如 spark-x2.5-1.7b
  3. 接口地址：形如 https://maas-api.cn-huabei-1.xf-yun.com/v2
点击 API Key 旁边的「复制」按钮。

注意区分：页面上可能还有 AppID、APISecret 等字段，那些都不是要填进零号工具的东西， 只要以 ak- 开头的那一个 API Key。
images/xinghuo-upgrade/04-调用示例与APIKey.png
待补截图：第二步调用示例区，需拍到 API Key（ak- 开头）、Model ID、接口地址，以及「复制」按钮。
重要：新密钥是「一段」，不是旧教程里的「两段」。
旧版 Spark Lite 的 APIKey:APISecret 冒号拼接格式已废弃。
现在只要 ak- 开头的单个字符串，直接粘贴，不要拼接、不要加引号。
5核对三项信息
把页面上显示的三项值和下表逐项比对。有一项对不上，调用就会失败， 而报错信息往往看不出是哪一项错了 —— 先核对能省掉一轮试错。
项目应显示为
接口地址https://maas-api.cn-huabei-1.xf-yun.com/v2
Model IDspark-x2.5-1.7b
API Key以 ak- 开头的长字符串

接口地址和 Model ID 零号工具已内置，你不需要手动填。
⚠️ 最后一步别忘了：回到零号工具的配置中心， 找到讯飞星火卡片，粘贴新 Key 覆盖掉旧的。
只开通服务而不回零号工具粘贴新 Key 的话，插件里存的还是那个调不动的旧配置。
常见问题：
  1. 提示「该 API Key 暂未开通模型服务」 —— 这是正常提示，点「开通服务」即可（第 3 步）。
  2. 报 401 / 「apikey not found」 —— 多半是把 Model ID 或接口地址当 Key 填了，或复制时带了引号/空格。只填 ak- 开头那一段。
  3. 报「model not found」 —— 开通的不是 Spark-X2.5-1.7B，回第 1 步确认选的是 1.7B。
  4. 提示额度不足 —— 「限时免费」有到期时间，到期后需重新开通或改用其他免费模型。
  5. 找不到「开通服务」按钮 —— 需要先勾选下方的协议复选框，勾上按钮才可点。

最后一步：填入零号工具

把刚才复制的 ak- 开头的 API Key 粘贴到下方，点击按钮跳转到 DSH 完成填充。
