讯飞星火 API Key 配置

Spark-X2.5-1.7B 限时免费，1M 超长上下文，国内直连

⚠️ 如果你以前配置过讯飞星火，请注意这里换了模型。
旧教程里的 Spark Lite 已被讯飞官方下架 —— 即使完成实名认证也领不到「无限量」礼包， 原来的配置必然调用失败。现已改用当前免费的 Spark-X2.5-1.7B。
你需要重新走一遍下面的流程、粘贴新的 API Key（新旧是两套互不相通的密钥，无法自动迁移）。 在你换新 Key 之前，零号工具的自动路由会把这个不可用的讯飞绕开、切换到其他可用模型 —— 界面上看起来一切正常， 但你实际上一直没在用讯飞。
讯飞星火是 4 个免费模型中注册流程最复杂的（需要手机号注册 + 创建应用 + 开通模型）。 如果觉得麻烦，可以先配置智谱和硅基流动（流程更简单），讯飞以后再补。
1注册并登录星辰 MaaS 平台
访问 https://maas.xfyun.cn/modelSquare， 用手机号注册并登录（默认即为免费版，自带免费资源，无需付费）。

这是讯飞官方的星辰 MaaS 平台（大模型一站式服务平台）， 与讯飞开放平台（console.xfyun.cn）是两个不同的平台，密钥不能通用。

2在模型广场找到 Spark-X2.5-1.7B
登录后进入「模型广场」（模型集市）页面，在筛选栏里选「限时免费」， 或直接搜索 Spark-X2.5-1.7B，点击模型卡片进入模型详情页。

详情页可以看到该模型的免费到期时间、接口地址、在线体验入口。找到后点击页面上的「API 调用」按钮。

3开通模型并关联应用
点击「API 调用」后弹出配置窗口，按提示填写：
  1. 模型服务 API 名称：随意填写，如「零号工具-DSH」
  2. 选择应用：如果已有应用，下拉直接选；如果没有则点「前往创建应用」，进入下一步
填写完成后点击「确定」。

4创建应用
上一步点了「前往创建应用」会跳到创建表单。应用信息随意填写即可，没有审核：
  1. 应用名称：如「零号工具-DSH免费模型」
  2. 应用描述：如「用于 DeepSeek Harness 零号工具的免费模型调用」
点击「提交」，创建成功后会自动跳回上一步的弹窗（此时应用下拉框里就有它了，选中并确定）。

5在「推理服务」页复制 API Key
提交后系统会跳到推理服务页面；如果没有自动跳转，请手动点左侧菜单的「推理服务」。 这个页面会列出你开通的模型服务，每条包含三项信息：
  1. API Key：以 ak- 开头的长字符串（形如 ak-f30b1********fc84b82e86a）—— 这就是要填进零号工具的东西
  2. Model ID：模型标识，形如 spark-x2.5-1.7b
  3. 接口地址：OpenAI 兼容接口，形如 https://maas-api.cn-huabei-1.xf-yun.com/v2
点击 API Key 旁边的「复制」按钮。

注意区分：页面上可能还有 AppID、APISecret 等其他字段，那些都不是要填进零号工具的东西， 只要以 ak- 开头的那一个 API Key。
images/xinghuo/06-推理服务页APIKey.png
待补截图：推理服务列表页，需清楚拍到 API Key（ak- 开头）、Model ID、接口地址三列，以及「复制」按钮。
重要：讯飞的新密钥是「一段」而不是「两段」。
v1.14.0 起，零号工具需要的是星辰 MaaS 平台的 ak- 开头的单个字符串， 不需要再用冒号拼接两个密钥（那是旧版 Spark Lite 的 APIKey:APISecret 格式，已废弃）。
正确示例：ak-f30b1a1b2c3d4e5f6a7b8fc84b82e86a
粘贴时不要带引号、不要带前后空格、不要把 Model ID 或接口地址一起复制进去。
6核对三项信息
把推理服务页显示的三项值和下表逐项比对。这三项只要有一项对不上，调用就会失败，而报错信息往往看不出是哪一项错了 —— 先核对能省掉一轮试错。
项目你页面上应显示
接口地址https://maas-api.cn-huabei-1.xf-yun.com/v2
Model IDspark-x2.5-1.7b
API Key以 ak- 开头的长字符串

接口地址和 Model ID 零号工具已内置，你不需要手动填 —— 但如果页面上显示的不一样， 说明你选的是别的模型（比如 Spark-X2.5-4B），请回到第 2 步确认选的是 1.7B。
常见问题：
  1. 报 401 / 「apikey not found」 —— 多半是把 Model ID 或接口地址当 Key 填进去了，或者复制时带了引号/空格。只填 ak- 开头那一段。
  2. 报「model not found」 —— 开通的不是 Spark-X2.5-1.7B，回第 2 步重新选。
  3. 提示额度不足 —— 「限时免费」有到期时间。到期后需要重新开通，或改用其他免费模型。
  4. 在旧的讯飞开放平台（console.xfyun.cn）找不到入口 —— 那是另一个平台，Spark Lite 已在那里下架。请到星辰 MaaS 平台（maas.xfyun.cn）操作。
  5. 零号工具里还显示「讯飞」但一直不可用 —— 你的本地配置仍是旧版 Spark Lite。请在配置中心重新粘贴新的 ak- Key 覆盖它。
Spark-X2.5-1.7B 限时免费、1M 原生上下文（长文档分析很省心），国内直连无需梯子。 它是 1.7B 的小模型，参数规模远小于智谱 GLM-4.7-Flash， 因此零号工具把它排在智谱和硅基流动之后 —— 需要更强的中文能力时优先用智谱。

最后一步：填入零号工具

把刚才复制的 ak- 开头的 API Key 粘贴到下方输入框，点击按钮将自动跳转到 DSH 并完成填充。
