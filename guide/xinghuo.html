为什么是「新模型」而不是老的 Spark Lite？
老的免费模型 Spark Lite 已被讯飞官方下架 —— 即使完成实名认证也领不到「无限量」礼包， 用它必然失败。现在改用当前免费的 Spark-X2.5-1.7B（1M 上下文，0 元/百万 tokens）。
如果你以前配置过讯飞，请走老用户更新指南。
讯飞是 4 个免费模型里注册流程最复杂的（需要手机号注册 + 创建 API Key + 开通服务）。 如果觉得麻烦，可以先配置智谱和硅基流动（流程更简单），讯飞以后再补。
1注册并登录讯飞开放平台
访问 https://www.xfyun.cn/， 点击右上角「立即注册」，推荐用微信扫码登录（最快）。

登录成功后进入顶部导航的「控制台」。

⚠️ 不需要实名认证。旧的 Spark Lite 需要实名才能领礼包，那个模型已经下架了； 现在的星辰 MaaS 平台用手机号注册即可直接使用免费模型。

2进入星辰 MaaS 平台，找到 Spark-X2.5-1.7B
从讯飞开放平台导航进入「星辰 MaaS 平台」（maas.xfyun.cn）， 或直接访问 https://maas.xfyun.cn/modelSquare 的「模型广场」页面。

页面里「星火模型」分类下能看到 Spark-X2.5-1.7B，卡片上标注了 1M 上下文 和 0 元/百万 tokens。点击它进入详情页， 然后点详情页上的「API 调用」按钮。

3在「API 调用」弹窗里创建 API Key
点「API 调用」后会弹出「第一步：选择 API Key」窗口。新用户这里会是空的， 点击「+ 创建 API Key」：
  1. API Key 名称：随意填写，如「零号工具-DSH」
  2. 提交：创建完成后，它会出现在 Key 列表里

注意：创建 Key 之后，还需要开通模型服务才能调用 —— 下一步。

4勾选协议，点「开通服务」
创建好 Key 后，弹窗会显示一句提示：
「该 API Key 暂未开通模型服务，点击下方「开通服务」按钮即可开通并正常调用。」
这句话是正常的，不是出错。它只是说 Key 建好了，但还没开通这个模型。

勾选「我已阅读并同意计费说明、服务协议及《用户使用须知》」， 然后点 「开通服务」。定价是 0 元/百万 tokens，开通不产生费用。

5复制 API Key
开通成功后，弹窗进入「第二步：调用示例」，并自动生成完整调用示例。 页面下方显示：
  1. API Key：以 ak- 开头的长字符串（形如 ak-f30b1********fc84b82e86a）—— 这就是要填进零号工具的东西
  2. Model ID：形如 spark-x2.5-1.7b
  3. 接口地址：形如 https://maas-api.cn-huabei-1.xf-yun.com/v2
点击 API Key 旁边的「复制」按钮。

注意区分：页面上可能还有 AppID、APISecret 等字段，那些都不是要填进零号工具的东西， 只要以 ak- 开头的那一个 API Key。

重要：讯飞的密钥是「一段」。
网上旧教程会让你把 APIKey 和 APISecret 用冒号拼起来 —— 那是已下架的 Spark Lite 的格式，现在不再需要。
正确示例：ak-f30b1a1b2c3d4e5f6a7b8fc84b82e86a
粘贴时不要带引号、不要带前后空格、不要把 Model ID 或接口地址一起复制进去。
6核对三项信息
把页面上显示的三项值和下表逐项比对。这三项只要有一项对不上，调用就会失败，而报错信息往往看不出是哪一项错了 —— 先核对能省掉一轮试错。
项目你页面上应显示
接口地址https://maas-api.cn-huabei-1.xf-yun.com/v2
Model IDspark-x2.5-1.7b
API Key以 ak- 开头的长字符串

接口地址和 Model ID 零号工具已内置，你不需要手动填。
常见问题：
  1. 提示「该 API Key 暂未开通模型服务」 —— 正常提示，点「开通服务」即可（第 4 步）。
  2. 报 401 / 「apikey not found」 —— 多半是把 Model ID 或接口地址当 Key 填了，或复制时带了引号/空格。只填 ak- 开头那一段。
  3. 报「model not found」 —— 开通的不是 Spark-X2.5-1.7B，回第 2 步确认选的是 1.7B。
  4. 提示额度不足 —— 「限时免费」有到期时间，到期后需重新开通或改用其他免费模型。
  5. 找不到「开通服务」按钮 —— 需要先勾选下方的协议复选框，勾上按钮才可点。
  6. 看到的是 Spark-X2.5（293B）而不是 1.7B —— 那个要收费（输入 0.96 元/百万 tokens）。本教程要用的是同名的1.7B 版本，卡片上标着「1M」和「0 元」。
Spark-X2.5-1.7B 限时免费、1M 原生上下文（长文档分析很省心），国内直连无需梯子。 它是 1.7B 的小模型，参数规模远小于智谱 GLM-4.7-Flash， 因此零号工具把它排在智谱和硅基流动之后 —— 需要更强的中文能力时优先用智谱。

最后一步：填入零号工具

把刚才复制的 ak- 开头的 API Key 粘贴到下方输入框，点击按钮将自动跳转到 DSH 并完成填充。
