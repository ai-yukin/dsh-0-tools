讯飞星火 API Key 配置

Spark Lite 永久免费，中文理解能力强，国内访问稳定

讯飞星火是4个免费模型中注册流程最复杂的（需要实名认证 + 创建应用 + 领取礼包）。如果觉得麻烦，可以先配置智谱和硅基流动（流程更简单），讯飞以后再补。
1注册账号并完成实名认证
访问 https://www.xfyun.cn/，推荐用微信扫码登录（最快）。登录后进入「用户认证中心」完成个人实名认证（需要填写真实姓名和身份证号，并完成人脸识别）。

注意：实名认证需要人工审核，通常需要等待一段时间（几分钟到几小时不等）。审核通过后会收到站内消息通知。
2进入「我的应用」页面
实名认证通过后，点击页面顶部「控制台」进入开发者后台，在左侧菜单找到「我的应用」，或直接访问 https://console.xfyun.cn/app/myapp。
3创建新应用
点击「创建新应用」按钮，进入创建应用表单。
4填写应用信息
填写应用信息：
  1. 应用名称：随意填写，如"零号工具-DSH免费模型"
  2. 应用分类：选择「应用-教育学习-学习」（或其他分类都可以）
  3. 功能描述：随意填写，如"用于DeepSeek Harness零号工具的免费模型测试"
填写完成后点击「提交」。
5应用创建成功
提交后应用立即创建成功（不需要审核），页面会显示应用的 APPID。点击应用名称进入应用详情页。
6进入 Spark Lite 服务页面
在应用详情页左侧菜单找到「星火认知大模型」→「Spark Lite」，点击进入 Spark Lite 服务页面。页面会显示：
  1. 实时用量：token余量、并发数、有效期
  2. http服务接口认证信息：APIPassword
  3. Websocket服务接口认证信息：APPID、APISecret、APIKey
7领取 Spark Lite 不限量礼包
在 Spark Lite 服务页面点击「领取无限量」按钮，弹出确认对话框后点击「确认」。领取成功后 token 余量显示为「无限」，有效期至 2036 年（永久免费）。
8获取 API 密钥
在 Spark Lite 服务页面下方找到「Websocket服务接口认证信息」，这里有三个值：
  1. APPID：应用唯一标识符（如 c77d9ba4）
  2. APISecret：API 密钥（base64 编码，如 YzQ2YTcxMmEzOGFkZDI1ZGM0ODA4M2I5）
  3. APIKey：API 密钥（32位十六进制，如 8489885e9902a4f8b8c801828e9bb203）
分别点击 APIKey 和 APISecret 旁边的「复制」按钮，把两个值都复制下来。
重要：讯飞需要两个密钥拼接！
零号工具需要的格式是 APIKey:APISecret（两个密钥用英文冒号拼接）。
例如：8489885e9902a4f8b8c801828e9bb203:YzQ2YTcxMmEzOGFkZDI1ZGM0ODA4M2I5
请把你复制的 APIKey 和 APISecret 用冒号拼接后，粘贴到下方输入框。
常见问题：如果调用时报「401 未经授权」，通常是因为：
  1. 没有完成实名认证
  2. 没有领取 Spark Lite 不限量礼包
  3. APIKey 和 APISecret 没有用冒号拼接（单独用 APIKey 会报错）
  4. 复制错了值（把 APPID 当成了 APIKey）
请回到第1、7、8步检查。
