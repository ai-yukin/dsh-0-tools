百度千帆 API Key 配置

ERNIE-Speed-8K 永久免费不限量，QPS 高达 50，国内访问速度快

1打开百度智能云
访问 https://console.bce.baidu.com/qianfan/，使用百度账号登录（也支持微信/QQ/微博扫码登录）。
2进入 API Key 管理
登录后进入千帆控制台，在左侧菜单栏找到「API Key」并点击。
3创建 API Key
点击右上角蓝色「创建 API Key」按钮。
4填写信息并创建
名称会自动生成（也可以自己改，如"零号工具"），权限选择「全部权限」，点击右下角「创建」按钮。
5复制 API Key
在列表中找到刚创建的 Key（以 bce-v3/ 开头），点击复制按钮（📋）。
💡 百度千帆 ERNIE-Speed-8K 是4个免费模型中并发能力最强的（QPS=50，比智谱免费版高50倍），适合作为主力免费模型。国内访问速度快，高频率日常使用无压力。

最后一步：填入零号工具

把你刚才复制的 API Key 粘贴到下方输入框，点击按钮将自动跳转到 DSH 并完成填充。
